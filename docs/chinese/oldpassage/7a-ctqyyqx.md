# 陈太丘与游期行

## 文学常识

本文选自《世说新语》，作者南朝·宋(临川王)刘义庆。这是一部致人小说集。

## 理解

本文着重写陈元方与客人的对话，表现了远方不仅 ==聪明机智== ，而且 ==明辨事理，守信重礼== 。一个 ==明白事理、落落大方、维护父亲与自己尊严== 的儿童形象跃然纸上，而 ==“无信”“无理”== 的客人形象也展现在读者面前。
