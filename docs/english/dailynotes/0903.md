## 词组

- an experienced counsellor 一个有经验的顾问
- get pimples 长粉刺
- none of + 复数名词/代词 （三者及以上）都不，谓语动词用单数或复数均可
- trouble sb. 使某人困扰
- be willing to do sth 愿意做某事
- seem to suffer from stress 似乎遭受压力
- suffer from = go through 经历，遭受
- calm strong emotions 平复强烈的情绪
- emotional changes 情绪变化
- behavioural changes 行为变化
- physical changes 身体变化
- social changes 社交变化
- be bothered by... = be troubled by... 被…困扰
- make one's own choices 自主做出选择
- have trouble (in) doing sth = have difficulty (in) doing sth 做某事有困难
- get along with sb = get on with sb 与某人相处
- ease the trouble 缓解问题
- show off 炫耀
- peer pressure 同伴压力
- under pressure 处于压力之下
- put pressure on sb 给某人施压
